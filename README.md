# Sala-fitness
Proiectul este scris in C++. Acesta retine informatii despre o sala fitness( clase, angajati, membrii, locatii). Se citesc date din fisierele clase.in, angajati.in, membrii.in si locatii.in si se retin in structuri. Astfel, la rulare se selecteaza o entitate din cele 4. Pentru fiecare se afiseaza o noua serie de comenzi prin care se pot adauga, elimina, sorta si cauta informatii.
